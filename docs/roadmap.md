# Дорожная карта и задачи

## Чек-лист (ближайшее)

- [ ] Фото + замеры: колёсные модули ×4 (общий план, разъём крупно,
      габариты, диаметр колеса, крепёжные уши, ход пружины)
- [ ] Фото + этикетки: батареи ×2, напряжение на разъёме мультиметром
- [ ] Фото: разъёмы лидара Delta-2A и Delta-2C PRO
- [ ] Мультиметр: уровень TX лидара (3.3 или 5 В — нужен ли делитель)
- [ ] TinkerOS/Armbian на SD, загрузка Tinker Board 2, SSH
- [ ] Armbian на Zero 2 W (проверка, на будущее)

## Бюджет допокупок

| Позиция | Комментарий |
|---|---|
| 2 × BTS7960 | по одному на борт |
| Buck 5 В / 5 А ×2 | одноплатник + запас |
| Выключатель 10 А | силовая линия |
| TB6612 | только если ток мотора щётки ≤1.5 А (ровер B) |
| USB-камера ×1–2 | FPV, потом стерео |
| OAK-D Lite / RealSense D435i | этап 2, опционально |
| Клеммники, DuPont, втулки М3, винты, стойки | расходка |
| LiDAR | НЕ покупаем — есть два из пылесосов |

## Этапы

1. Замеры и распиновка
2. Печать адаптеров колёс → лонжероны → рама
3. Электрика
4. Софт моторов + энкодеров на Tinker Board 2
5. Первый выезд (телеуправление)
6. LiDAR'ы → LaserScan → SLAM
7. Стерео → depth → препятствия
8. Автономия: одометрия + IMU, навигация

## Идеи на потом (ровер B и не только)

- Ровер B: 2WD на коллекторных моторах турбощёток, колёса TPU,
  Zero 2 W. Без энкодеров — чистое телеуправление.
- Циклонный пылесос для мастерской из турбины всасывания.
- Мини-станок (гравёр/шлифовка) на втором моторе турбощётки.
- Манипулятор роверу A: приводы сочленений — те же моторы щёток.
- Автокормушка из моторчиков боковых щёток.
- Поворотная мачта камеры (если откажемся от двух лидаров).
