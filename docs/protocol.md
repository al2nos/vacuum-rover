# Протокол обмена данными (MQTT)

Транспорт — MQTT 3.1.1. Брокер: mosquitto на VDS `10.77.0.1:1883`
(доступ только из VPN 10.77.0.0/24, логин/пароль на узле).
Для браузера брокер слушает WebSocket `127.0.0.1:9001` (через nginx).

## Топики

| Топик | Направление | QoS | Retain | Содержимое (JSON) |
|---|---|---|---|---|
| `rover/<node>/telemetry/system` | узел → все | 0 | нет | `{"cpu": %, "mem": %, "temp": °C, "uptime": ч, "ts": epoch}` |
| `rover/<node>/telemetry/lidar` | узел → все | 0 | нет | `{"rate_hz": , "packets_ok": , "packets_lost": , "rpm": }` |
| `rover/<node>/status` | узел (LWT) | 0 | **да** | `online` / `offline` (last will) |
| `rover/<node>/cmd/teleop` | пульт → узел | 0 | нет | `{"vx": м/с, "wz": рад/с, "ts": epoch}` |
| `rover/<node>/config` | узел → все | 0 | **да** | текущий конфиг узла (любой JSON) |
| `rover/<node>/config/set` | пульт → узел | 0 | **да** | новый конфиг; узел применяет и публикует в `config` |

`<node>` = имя узла: `tinker`, `opi3`, `zero2w`…

## Соглашения

- Телеметрия системы: **1 Гц**. Телеметрия лидара: 1 Гц (агрегаты).
- Все временные метки — Unix epoch (секунды, float).
- `ts` в телеметрии — время замера на узле; брокер не подменяет.
- LWT: при подключении узел публикует retained `online` и регистрирует
  will `offline` — пульт так определяет живость узла.
- Конфиг — единственный retained-канал управления: узел при старте
  читает `config/set`, применяет, публикует результат в `config`.
- Телеуправление: `vx` — линейная скорость (м/с, + вперёд),
  `wz` — угловая (рад/с, + против часовой). Таймаут безопасности на
  узле: 0.5 с без пакетов → стоп.

## Пульт

Веб-пульт: `https://3dlb.ru/console/` (логин/пароль сайта).
Сервис `rover-console` на VDS: FastAPI + SQLite + WebSocket,
подписка на все топики `rover/#`. API:

- `GET /api/nodes` — узлы, живость, последние метрики
- `GET /api/history?node=&metric=&minutes=` — история из SQLite
- `GET/POST /api/config/<node>` — чтение/запись конфигурации
- `WS /ws` — live-поток метрик + приём команд телеуправления

## Доступы (хранятся на VDS, НЕ в репозитории)

- `/etc/mosquitto/passwd` — пользователи брокера (root:mosquitto, 640)
- узлы: `tinker`, `opi3`, … ; сервисы: `console`, `agent`
- Пароль консоли: `/opt/rover-console/.env` (`ROVER_MQTT_PASS`)
- Пароли выдаёт владелец или генерирует агент с доступом к VDS;
  в репозиторий — не коммитить. После смены пароля в passwd —
  `systemctl restart mosquitto`.
