# Стереозрение

Цель: дальнометрия по всему полю зрения + детекция препятствий,
недостижимых для лидара (низкие предметы, провода).

## Варианты

1. **2 × USB-камеры на жёсткой планке** (база 80–100 мм), OpenCV StereoSGBM.
   Плюс: почти бесплатно. Минусы: нет аппаратной синхронизации (глубина
   «плывёт» в движении), CPU ×2, на RK3399 ~5–10 FPS при 640×480.
2. **OAK-D Lite** — depth считается на чипе Myriad X внутри камеры,
   USB 3.0 (у Tinker Board 2 есть), ROS 2 из коробки. Рекомендуемый путь.
3. **Intel RealSense D435i** — depth + встроенная IMU (полезна для
   фьюжна одометрии скид-стира).

CSI-камеры на разъём Tinker Board 2 — не рекомендуются (капризные драйверы).

## Порядок внедрения

Этап 1: одиночная USB-камера — FPV + телеуправление.
Этап 2: стереокамера (OAK-D Lite) — depth для автономии.
Код калибровки и SGBM с вебок переезжает почти без изменений.

## Крепление

- Мачта по центру носа, площадка шириной ~120 мм (влезет всё).
- Жёсткость базы критична: перекос камер на 1 мм = шум глубины.
- Калибровка: шахматка, OpenCV stereoCalibrate.
