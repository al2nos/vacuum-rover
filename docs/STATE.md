Mechanic / Driver / Scout — функциональные шапки, см. AGENTS.md).

сайт https://3dlb.ru (/kb/, /stages/). После правки docs/ — синхронизировать
сайт (`deploy/build_site.py`), пометка `site-sync: pending` если нет доступа.

## Сессия 2026-11-24 (итоги)

Сделано за сессию:

- Инфраструктура мониторинга на VDS: mosquitto (10.77.0.1:1883 + WS
  127.0.0.1:9001) + rover-console на FastAPI+SQLite+WebSocket
  (/console/) + node-agent для узлов. Весь контур ~180 МБ RAM.
- rover-console: карточки узлов (LWT online/offline), временные
  графики по каждому датчику (30 мин истории + live), карта лидара
  (canvas, вид сверху, затухающий след), панель активности датчиков
  (msg/s, возраст скана), джойстик teleop, редактор конфигурации.
- Формат сканов в MQTT: `telemetry/lidar` с полем `r` [мм], 360 лучей;
  скаляры (rpm, rate_hz, потери) — отдельно, 1 Гц. Сканы в SQLite
  не пишутся (решение D13).
- node-agent пробрасывает сканы декодера из $ROVER_SCAN_FILE
  (/run/rover/scan.json) в telemetry/lidar — мост «декодер → консоль».
- Проверка end-to-end эмулятором fake_publisher: сканы комнаты 6×4 м,
  карта/графики/активность/LWT — всё работает (скриншоты у владельца).
- Сайт-зеркало: пересбор под альбомную ориентацию (ширина 1380 px,
  двухколоночные списки, таблицы на всю ширину, сетка карточек KB),
  ссылка «Пульт» в меню всех страниц (лендинг, дашборд, KB, этапы).
- Исправления: относительные пути API/WS в консоли (баг за nginx-
  префиксом /console/), синхронизация пароля broker-юзера agent после
  ротации, исключение служебных start/step из метрик.
- План ROS 2/Nav2 зафиксирован: этап 3 в roadmap (Jazzy на Armbian
  24.04 Тинкера, rosbridge-прокси на VDS, вкладка навигации),
  границы каналов MQTT/ROS 2/rosbridge в protocol.md и architecture.md.
