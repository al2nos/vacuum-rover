## Модель работы

Агенты взаимозаменяемы: любой агент выполняет любую роль (Navigator /
Mechanic / Driver / Scout — функциональные шапки, см. AGENTS.md).
Смена агента в середине задачи — по протоколу эстафеты (Handoff в issue).

База знаний в двух местах: канон — `docs/` в GitHub (main), зеркало —
сайт https://3dlb.ru (/kb/, /stages/). После правки docs/ — синхронизировать
сайт (`deploy/build_site.py`), пометка `site-sync: pending` если нет доступа.
