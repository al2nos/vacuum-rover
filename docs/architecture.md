# Архитектура ровера A

4WD-ровер, собранный из двух роботов-пылесосов. Скид-стир: левый и правый
борта крутятся независимо, поворот — разностью скоростей.

## Вычислители

| Плата | Роль |
|---|---|
| Tinker Board 2 (RK3399, 2 ГБ) | Мозг: лидара, стереозрение, энкодеры, ROS 2, навигация (Nav2) |
| Orange Pi 3 (2 ГБ) | Телеуправление, видеострим, дашборд (шлюз) |
| Orange Pi Zero 2 W (4 ГБ) | Резерв → ровер B; план Б для Nav2 при нехватке RAM |

Tinker Board 2 сильнее OPi 3 (ядра A72 против только A53) — поэтому
перцепция и навигация именно на нём. Распределённые вычисления
«одна плата под камеру» отвергнуты: стереоподбор требует оба кадра
на одной машине, а пересылка кадров по сети только добавляет латентность.

## Каналы данных (три, не путать)

| Канал | Технология | Для чего |
|---|---|---|
| Шина устройств | MQTT (mosquitto на VDS 10.77.0.1:1883) | телеметрия 1 Гц, сканы лидара (JSON r,мм), LWT-статус, телеоп-резерв, конфиги. Лёгкий, работает на любом железе |
| Автономный стек | ROS 2 Jazzy (борт, только Tinker) | LaserScan, tf, SLAM, Nav2, /cmd_vel. Не выходит за борт наружу кроме rosbridge |
| Пульт ↔ ровер | rosbridge (WebSocket-JSON, порт 9090 на Тинкере; nginx на VDS проксирует /rosbridge/) | карта (/map), поза AMCL, путь, цели Nav2. Рендерится roslibjs в браузере, VDS — чистый прокси |

Граница жёсткая: карты и пути через MQTT **не гонять** (объём + частота),
мониторинг через rosbridge не дублировать. Детали — docs/protocol.md.

## VDS 3dlb.ru — хаб, не борт

WireGuard 10.77.0.0/24, сайт-зеркало базы знаний (/kb/, /stages/),
rover-console (/console/: карточки узлов, графики по датчикам, карта
лидара, активность, джойстик, конфиги), mosquitto. 380 МБ RAM / 1 CPU —
поэтому только лёгкий стек, ROS 2/Nav2 на нём не поднимается.

## Сенсоры

- LiDAR Delta-2C PRO — нос (автономный мотор, только питание 2.5–3.3 В)
- LiDAR Delta-2A — корма (мотор требует ШИМ с PID до 6 Гц)
- Стереокамера — мачта, ярус ~15–20 см (варианты: 2×USB / OAK-D Lite / RealSense D435i)
- 4 × энкодера колёс — одометрия, усреднение по борту, детект пробуксовки

## Привод

- 4 × колёсные модули от пылесосов (2 от STYTJ02YM + 2 от C103).
  Важно: на каждом борту по одному колесу каждой модели, чтобы разница
  диаметров/редукций была симметричной.
- 2 × BTS7960: один канал = один борт (2 мотора параллельно). Моторы
  в ходу 1–2 А, стопор 3–4 А — запас огромный.
- Моторы питаются напрямую от батареи 14.4 В (штатный режим).

## Ограничения

- Скид-стир: одометрия в поворотах врёт (скольжение) → апгрейд IMU
  (MPU9250) для фьюжна позы.
- Без жёсткой синхронизации стереокамер глубина на скорости «плывёт».
- Nav2 + slam_toolbox + декодер на 2 ГБ RAM Тинкера — впритык
  (zram/swap, localhost-only DDS). План Б: Nav2 → Zero 2 W (4 ГБ).
