# Ровер A — 4WD из двух роботов-пылесосов

Основной ровер проекта `vacuum-rover`. Шасси собирается из доноров:

- **Mi Robot Vacuum-Mop P** (STYTJ02YM) — плата CRL200S_01
- **Mijia Robot Vacuum-Mop 3C Enhanced** (C103) — плата CTL_C103_MAIN_V03

## Архитектура

```
Tinker Board 2 (RK3399, 2 ГБ) — мозг восприятия и навигации
├── 2 × LiDAR (Delta-2C PRO нос, Delta-2A корма) → LaserScan → SLAM
├── Стереокамера → depth (OpenCV SGBM или OAK-D Lite)
├── 4 × энкодера колёс → одометрия
└── ROS 2 → управление BTS7960

Orange Pi 3 (2 ГБ) — телеуправление, стрим, дашборд (шлюз)
Orange Pi Zero 2 W (4 ГБ) — резерв / ровер B
```

Привод — **скид-стир**: 4 подпружиненных колёсных модуля, левый борт
на одном канале BTS7960, правый — на втором.

## Железо

| Узел | Деталь |
|---|---|
| Мозг | Tinker Board 2 (2 ГБ) |
| Привод | 4 × колёсные модули от пылесосов |
| Драйверы | 2 × BTS7960 (по борту) |
| Лидары | Delta-2C PRO (носовой), Delta-2A (кормовой) |
| Зрение | стереопара USB / OAK-D Lite |
| Питание | батарея 4S 14.4 В из пылесоса → buck 5 В/5 А |
| Рама | 3D-печать PETG, модульная (FF AD5X ×2) |

## Подключение

- Дельта-2A: JST PH 5-пин (TX, GND, MOT−, +5V, MOT+). ШИМ 10 кГц на MOT_EN
  с PID до 6 Гц. UART 115200.
- Дельта-2C PRO: TX → RX UART1 (пин 10) Tinker Board 2, мотор — постоянные
  2.5–3.3 В, протокол 0x11/0x13, 115200. Полный дешифровщик: библиотека
  kaiaai/LDS + адаптация `delta_2a_pi.py`.
- Уровень TX лидара проверить мультиметром: если 5 В — делитель на RX.
